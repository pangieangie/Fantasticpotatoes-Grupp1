The Fantastic Potatoes Algorithm

We all struggle to find a good series sometimes, even thou we have countless streaming services, it often feels surprisingly difficult to find something that fits our mood, the interest right now or the kind of story we want at the moment. This frustration became the foundation of our project. We wanted to design an algorithm that helps users to find the right streaming platform based on personal preferences, rather than broad categories or generic suggestions. Our algorithm helps users find the streaming platform that best matches their personal preferences. It does this by checking four criteria the user selects: language, actor, genre, and topic.

Step 1: Input specification

The algorithm goes through every show in our dataset and checks whether it matches all four user selected criteria. If a show fits, it is added to a list of matching shows that looks like this:

  • - matchingshows: A list of all shows that satisfy all user criteria
  • - matchingplatform: A dictionary where each key is a platform name and each value is a list of matching shows available on that platform

Step 2: Output specification

Each matching show is then connected to the streaming platforms where it is available. The algorithm stores this in a dictionary, making it easy to see which platform offers the most relevant content.

Step 3: Select matching shows

In the next step the algorithm returns a list of shows that match the user’s preferences and a recommendation of platforms that contain those shows This gives the user a simple, personalized way to decide which streaming service that fits them best, based on what they actually want to watch.

Step 4: Output generation

To improve the user experience, the algorithm sorts the results so that shows with the highest rating appear first.

Why This Algorithm Fits Our Dataset

This algorithm works well because the dataset is structured with comparable attributes and each attribute directly corresponds to a user preference. The relationship between shows and platforms is simple and easy to compute and the algorithm can be expanded with more criteria in the future. This aligns with the project’s conceptualization goals: “Our goal is to create a structured, meaningful dataset that an algorithm can use to make smarter, more personalized recommendations.”
